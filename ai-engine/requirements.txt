# Runtime dependencies for ai-engine (the real STT -> LLM -> TTS stack).
# Mirrors [project].dependencies in pyproject.toml; used by the Dockerfile.
#
# Version floors are the ones actually verified on this machine (see
# README.md "Verified versions"); ceilings are the next major, so a breaking
# release cannot land silently.

# NOTE ON SIZE: torch+transformers are needed by the MiniLM sentence encoder in
# app/knowledge/embeddings.py (the retrieval primitive that outlived the intent
# model). The Dockerfile installs CPU-only torch from the PyTorch CPU index to
# keep the image from pulling multi-GB CUDA libraries. The LLM itself is a
# remote HTTP provider and pulls no ML runtime at all.
